images, not screenshots: the real UI is captured on the day, these sit behind

## Using them

- Source size is 752×1392 (9:16). Scale to a 1080×1920 canvas (about 144%) and
  crop if needed — do not stretch them wider than 9:16.
- Leave type off the image: set it in the edit in ivory (`#f2ecdd`) on ink
  (`#10171b`), small mono caps for labels, display face for the headline.
- Grade to match the live site, not the other way round: if a still looks
  warmer than the board's `#10171b` ink, pull the shadows cooler.
- Nothing here shows a real person, applicant, commission or member count, so
  they are safe to post without blurring.

## Note

Generated with an image model from the palette and mood of the site. If the
brand palette changes, regenerate rather than recolour — the film grain and
light falloff do not survive a hue shift cleanly.
